# Diseño visual

La aplicación debe sentirse como un juego de mesa moderno.

Evitar:
- Bootstrap
- Dashboards corporativos
- Tablas densas
- Animaciones

Usar:
- Esquinas redondeadas
- Tarjetas
- Ilustraciones protagonistas
- Colores definidos

Paleta:
#073B4C
#118AB2
#06D6A0
#EF476F
#FFD166

No usar hover como interacción principal.
Todo debe funcionar perfectamente en móviles.
